Chessist

Real-time chess analysis overlay powered by computer vision and Stockfish

Get started

No browser extensions. No game integration.

Just screen capture + vision + engine.

Works with Chess.com, Lichess, or any chess interface.

How it works

Screen → Board Detection → Template Matching → FEN → Stockfish → Best Move

Features

◉

Live Board Detection

Automatically finds and tracks the chess board on your screen.

◇

Template-Based Vision

Matches pieces using normalized correlation — no ML models needed.

⚙

Stockfish Integration

Configurable depth, time, hash, and threads for analysis.

▶

Auto-Play Mode

Optionally execute moves with human-like mouse movements.

▤

Modern Overlay

Clean tkinter UI with dark/light themes.

⊞

Cross-Platform

Runs on Linux and Windows (standalone builds available).

Quick Start

Prerequisites

  • Python 3.10+
  • Stockfish — Download or apt install stockfish
  • Templates — Piece images in templates/

Install

git clone https://github.com/Kaleab-Ayenew/chessist.git
cd chessist
python -m venv .venv && source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -e .

Run

python main.py

The overlay opens. Click Start Agent, open your chess game, and watch the magic.
